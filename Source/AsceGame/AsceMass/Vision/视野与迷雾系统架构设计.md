# 视野与迷雾（Visibility / Fog）系统——实现现状

> 本文档为**当前代码实现**的基线记录（早期理论稿已被删除/代码大幅演进，本文件以代码为准，后续改动同步此处）。
> 模块目录：`AsceMass/Vision/`，另含 FlowField 侧的 CostField footprint observer。

## 1. 目标与边界

- Server/Client 各自跑同一套确定性视野计算（结果不网络同步）。Server 用可见集过滤复制；Client 用本队可见集做表现。
- 地形常显；视野只决定"某位置的 entity 是否可见"（entity 覆盖格任一可见即可见）。
- 挡视野的只有建筑：`FAsceGridFootprintFragment`（`SizeX/SizeY/OcclusionHeightCm`），**不与寻路 cost/block 共用**。
- 单位不挡视野；单位贡献视野（位置格 + `He`（格高+眼高）+ `SightRadius`）。

## 2. 文件与职责

- `Vision/AsceVisionDefines.h/.cpp`：格常量/换算、队伍键打包（`PackTeamKey`/`GetTeamIndex`/`GetTeamId`、`MaxTeamCount=16`）、圆行区间表、`LogVision`、整除硬约束校验。
- `Vision/AsceVisionFragments.h`：`FAsceVisionViewFragment`（SightRadius/EyeHeightCm，复制）、`FAsceVisionFogStateFragment`（本地上帧贡献状态 `LastVisionCellIndex/LastHe/LastR/LastTeamKey`，不复制）。
- `Vision/AsceVisionHeightMap.h/.cpp`：静态高度场（本地初始化、暂全 0 + Set 接口）+ 动态遮挡层（footprint 局部写/清）+ `GetEffectiveHeight = max(静态,动态)`。
- `Vision/AsceFogSubsystem.h/.cpp`：核心数据/算法（见 §3~§5）。
- `Vision/AsceFogProcessor.h/.cpp`：每帧单位 diff 驱动（手动 Run）。
- `Vision/AsceVisionOcclusionObserverProcessor.h/.cpp`：Server 观察 footprint Add/Remove → 写/清遮挡（OcclusionHeightCm）。
- `Vision/AsceVisionViewRemoveObserverProcessor.h/.cpp`：单位消亡（ViewFragment Remove）→ 按 FogState 旧参数下线贡献。
- `FlowField/AsceCostFieldFootprintObserverProcessor.h/.cpp`：Server 观察 footprint → CostField 阻挡写 255/回滚 1。

## 3. 数据结构（格中心）

- `FGridResult`：源档结果 `{ Bits; int32 Occupants }`。
- `FTeamCellData`：每格每队 `{ uint16 VisibilityCount; TMap<uint64(He,R), FGridResult> SourceParms; }`。
- `FGridInfo`：每格 `{ FCriticalSection Lock; TArray<FTeamCellData> Teams; }`（Teams 惰性按队伍 index 扩）。
- 每队可见**投影**：`TeamProjections[teamIndex]` = 全图 1bit/格、行主序（InitializeVisionMap 固定分配 `MaxTeamCount` 份；查询/复制过滤/渲染读它）。
- `ActiveResults`：活跃源档有序数组（按 `(CellIndex,TeamKey,He,R)` 排序），供遮挡翻转遍历；本体只在帧末单线程修改。
- 变更分片 `PendingChangeShards`：并行阶段 push `FChangeOp{Key,bRemove,RemoveBits}`，帧末统一处理。

## 4. 数据流

1. `FogProcessor`（手动 `Executor::Run`，`ParallelForEachEntityChunk`，`GameThreadOnly=false`）逐单位 diff：读位置/team/眼高算 `(cell,He,R)`，与自身 FogState 比较；变化则：
   - `AddContribution`：源格锁内 建/占档（Occupants、当场 flood 写 Bits）、`PushPendingChange(add)`
   - `RemoveContribution`：源格锁内 减占/删档（拷出旧 Bits）、`PushPendingChange(remove)`
2. 帧末 `ProcessHeightChanges()`：
   - 先 `ProcessPendingChanges()`（单线程）：drain 分片，按**档最终存在性（Occupants）**决定：remove→若档已消失则从 ActiveResults 删 + 用旧 Bits `apply −1`；add→若档有人占且未登记则登记 ActiveResults + 用格内 Bits `apply +1`（同 key 多次 add 只 apply 一次）
   - 若遮挡 dirty 非空：遍历 ActiveResults，命中档"锁内快照旧 Bits → 锁外 −1 → 短锁重算写回 → 锁外 +1"
3. 查询/过滤读 `TeamProjections`；`apply`（`ApplyBitsToTeamCounts`）逐目标格加锁更新 `VisibilityCount`、投影位用原子 `InterlockedOr/And` 写（跨格共享 word）。

## 5. 并发模型

- 单位 diff 并行；写路径在"源格锁内建删档"与"分片 trylock 塞变更"。
- `ActiveResults` 与 ±apply 只在帧末单线程（顺序与线程交错解耦，按最终状态判定）。
- `ApplyBitsToTeamCounts` 对每个目标格持格锁（不重入：调用点不在持锁中）。
- 变更分片数量取 worker 线程数上界；push 用 `InterlockedCompareExchange` 试锁，全忙回退第一片。

## 6. 查询接口

- `GetTeamVisibleBits(TeamKey)`：只读投影（不存在/null 返回）。
- `IsCellVisible / IsCellVisibleAtWorld / IsEntityVisible(TeamKey, Geometry)`：单位用半径圆行区间、建筑用 footprint，对投影行段批量测试。
- 复制过滤（`Networking/Core/AsceUnitReplicator.cpp`）在 `ProcessClientReplication` 开头按 client→team 覆写 LOD（决策者入口）。

## 7. 队伍键

打包 `int32 = (Index<<16)|(id&0xFFFF)`：index 高16（数组下标），id 低16（标识）。数组一律按 index；`MaxTeamCount=16`。Fog 侧各入口对 index 越界/负值有守卫。`SetClientTeam(ClientIndex, TeamKey)` 注册 client→队伍（gameplay 层待调）。

## 8. 遮挡与寻路

- footprint：`FAsceGridFootprintFragment`（`SizeX/SizeY/OcclusionHeightCm`，AABB、按 flowfield 格）。无重叠约束，无需引用计数。
- 视野侧 Observer 写动态遮挡层（局部，dirty 区域入有序 `OcclusionDirty` 驱动翻转）。
- 寻路侧独立 Observer 写/回滚 CostField（255/1）。两模块各自订阅同一 footprint 事件，互不读对方数据。

## 9. Client 表现（现状与待办）

- ISM 渲染已另有实现（本模块不涉及）。
- 待做：
  - 可见性叠层（雾效纹理）：把本队 `TeamProjections` 转可见纹理供地面叠层采样（方案见 §10 备注）。
  - 建筑摧毁延迟表现：依赖建筑 entity 复制与死亡信号（建筑体系未建）。

## 10. 遗留/待办

- 静态地形高度来源/烘焙（当前全 0 + `SetStaticHeight*` 入口）。
- 建筑 trait / 放置流程（Observer 的事件源）；`AsceCostFieldFootprint` 与其一同上线。
- `SetClientTeam` 的 gameplay 注册点（PIE 冒烟可临时 SetClientTeam(0,0)）。
- footprint footprint→Vision 尺寸 = `GRID_SIZE/VisionCellSize` 整除校验（`ValidateCellSizeConfig`）。
- 雾效纹理：每队投影导出为 R8 图（格→像素，含地图原点/格尺寸→UV 换算），材质叠加；更新按可见变化/低频。

## 11. 备注（决策记录）

- 挡视野数据放在 `FAsceGridFootprintFragment.OcclusionHeightCm`（"挡视野=建筑=挂 footprint"），不再设独立遮挡 fragment。
- 早期"结果全局 map"与"每帧占位+flush"方案已废除；现为：源结果进格 + 变更分片 + 帧末按最终状态 apply。
- `GameThreadOnly=false`；查询在复制期 GT 读投影。
